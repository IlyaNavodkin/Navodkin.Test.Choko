# Visual fidelity plan

Поручение пользователя: приблизить работающий React-мок к выбранным изображениям по внешнему виду и композиции. Область — изолированный UX preview; перенос в native/product UI этим этапом не выполняется.

Кейсы: `01-calm-workspace.png`; старт: `04-repositories.png`; прогоны: `05-run-overview.png`; выполнение: `06-run-execution.png`; Git: `07-git.png`; диалоги: `08`–`11`. Растровые изображения служат эталоном оформления, интерфейс остаётся настоящим React с редактируемыми данными.

- [x] Восстановить пропорции chrome/дерева/документа, вложенность дерева, крупные иконки, ритм отступов; приблизить кейс к reference на 1586×992.
- [x] Оформить поверхности, бордеры, выделения, статусы и основные кнопки через существующие `--app-*`, без новой палитры или UI Kit.

- [x] Перестроить выполнение прогона по reference: список кейсов слева, этапы и проверки в документе, итог и закреплённая нижняя панель Save/next. Сохранить snapshot и dirty guards.
- [x] Перестроить Git по reference: панели списка/композера и сравнения, читаемые before/after, отдельные pull/push, без наложений и потери точного выбора файлов.
- [x] Привести диалоги и error/recovery states к общему визуальному языку, сохранить keyboard/focus и все действия.
- [x] Самостоятельно проверить браузерные скриншоты основных экранов и диалогов на 1586×992; проверить 1280×900 и 760×900, ключевые сценарии и отсутствие ошибок.
- [x] Выполнить TypeScript, frontend tests, check:ui и production build. Сохранить реальные скриншоты и описать оставшиеся различия.

## Constraints

Последовательная работа через одного `gpt-6.1-sol`, medium; основной агент проверяет результат. Не изменять Rust/IPC/форматы/репозитории, не включать mock entry в production build. Палитра Citadelic и общие исходные tokens остаются прежними; допустимы CSS Modules, композиция и scoped настройка UI primitives. Не добавлять неработающие элементы ради сходства. Редкие ошибки остаются демонстрационными состояниями.

Композиция и оформление приближены к изображениям, но это не гарантия пиксельного совпадения растрового эталона: остаются настоящие demo-данные, системная типографика, дополнительные рабочие фильтры и controls, токены Citadelic. На небольшом окне документ и diff прокручиваются локально. Данные по-прежнему в памяти; перенос в продуктовые компоненты и реальный IPC — следующий отдельный этап.
