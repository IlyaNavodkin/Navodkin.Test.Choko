# Proposal

Статус: draft для обсуждения, 2026-10-18. База — текущее приложение `app/` (NW.js + React + TypeScript).

## Why

Из прогона тест-кейса нужно быстро создавать баг-репорт: приложить скриншот или GIF, а затем легко скопировать всё в Jira. Сейчас в приложении есть только notes строки прогона и PDF-отчёт; в пожеланиях к приложению (`app/.docs/feedback.md`) этот сценарий уже описан — «copy-able defect section … paste into work item tracking system (devops, jira, etc.)». Пользователь подтвердил: экспорт первой итерации — копирование текста и вложений, без API-интеграции.

## What Changes

- Новая сущность **BugReport**: заголовок, серьёзность, статус, привязка к кейсу и прогону, снапшот контекста (упавшие шаги и комментарии, тестер, дата, окружение-аргументы, ветка и commit), описание, вложения.
- Создание из прогона: кнопка на строке кейса (fail/blocked и вручную), автозаполнение из **снапшота прогона**, а не из живого кейса.
- Вложения: скриншоты и GIF через paste/drag/выбор файла; просмотр, включая анимацию GIF.
- Хранение: `.casewright/bugs/<uuid>/report.md` + `attachments/` — отдельно от кейсов и прогонов, читаемо без приложения.
- Экспорт в Jira: «Copy for Jira» (Jira wiki markup с шагами, окружением, ссылкой на прогон), копирование изображения в буфер, открытие папки вложений. REST API Jira — вне объёма.
- Список багов в прогоне и в кейсе; PDF/JSON-отчёт прогона включает дефекты.
- Вне объёма: Jira/ADO API, запись GIF/видео экрана внутри приложения, автозакрытие дефектов, кастомные поля Jira.

## Capabilities

### New Capabilities

- `bug-reports`: создание и ведение баг-репортов из прогона, вложения и экспорт в трекер через копирование.

### Modified Capabilities

Нет.

## Impact

Новые `schemas/bug-report.ts`, `services/format/bug-report.ts`, `services/bug-reports.ts`, store slice, представление списка/редактора; правки `RunGrid`/`RunCaseCard`/`RunGuide` (кнопка создания и список дефектов), `services/report/*` (раздел дефектов), `lib/nwjs.ts` (клипборд/открытие папки). Ссылки на `arguments` и `link` используют справочник (change `add-reference-book`); изображения — ассеты (change `add-rich-text-and-images`).
