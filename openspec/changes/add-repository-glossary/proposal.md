# Proposal

## Why

Кейсы повторяют сокращения, определения и ссылки на внешние документы. Пользователь поручил добавить сущности с описанием и/или ссылкой и использовать их как общий слой пояснений. В исследованном Casewright `utils/variables.ts` решает подстановку дат, а не эту задачу; отдельного справочника в изученном editor/use-case слое нет.

## What Changes

- Уточнение 2026-10-17 в рамках `add-playwright-automation`: новый тип «Окружение» с типизированными несекретными значениями (например prod/stage → host/baseUrl), выбираемыми в аргументах автотеста по entry ID/key. Обычные описания/Markdown не становятся variables; запуск фиксирует snapshot значений и revisions. Native storage и UI расширения ещё требуют реализации.
- Новый раздел «Справочник» репозитория: термины, сокращения, документы; название, описание, необязательный URL, альтернативные названия, архив.
- Подтверждено пользователем: сущности с объяснением или ссылкой. Типы, название раздела, stable ID, Markdown-хранение и snapshot пояснений — предлагаемые решения этого change.
- Первый разрешённый срез: интерактивный каталог в изолированном `ux-preview.html`, создание/редактирование, поиск/фильтры, архив, явное сохранение в памяти и защита черновика. Без записи пользовательских файлов.
- Следующие срезы: Rust-хранение, вставка ссылок из кейсов, места использования, неизменяемые пояснения в snapshot-прогонах, scoped Git.
- Вне объёма: загрузка/индексация внешних документов, вложения, авторизация в сторонних системах, автоматическая подстановка текста, полнотекстовый поиск по интернету и миграция Casewright.

## Capabilities

### New Capabilities

- `repository-glossary`: каталог пояснений и ссылок, стабильная адресация, безопасное хранение и использование в кейсах/снимках.

### Modified Capabilities

Нет: существующие спецификации MVP остаются открыты; расширение интеграции описано требованиями новой capability.

## Impact

Сейчас: React UX preview, локальный UI Kit, tests и документация. Далее: отдельный glossary Rust service и типизированный IPC, session/path/revision проверки, watcher/FIFO, run snapshot writer и Git scope. Основной формат `.casewright` не меняется. Предлагается расширение `.testoritto/glossary/`, создаваемое только при первом явном сохранении записи; выбор пути и native round-trip ещё требуют реализации и проверки. Native приложение не получает сущность от одного наличия прототипа.
