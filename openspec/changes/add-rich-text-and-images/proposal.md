# Proposal

Статус: draft для обсуждения, 2026-10-18. База — текущее приложение `app/` (NW.js + React + TypeScript).

## Why

Текущие текстовые поля кейса — `<textarea>` с самодельной панелью форматирования (`ObjectiveEditor`, `SetupControl`); изображения не поддерживаются ни в редакторе, ни в просмотре. Пользователь требует перевести текстовый редактор на **TipTap** и добавить изображения: вставку в текст, показ в режиме просмотра и фиксированную миниатюру в режиме редактирования без изменения размера и перемещения.

## What Changes

- TipTap как редактор для полных текстовых полей: Objective, тело Setup, Notes прогона, описания справочника и баг-репортов. Markdown остаётся внешним форматом на диске — HTML/JSON TipTap никогда не пишется в файлы.
- Консервативный набор возможностей (bold/italic/strike, списки, заголовки, code, ссылки, таблицы), режим исходника для неподдерживаемого синтаксиса, явная деградация без потери содержимого.
- Изображения как общие ассеты репозитория: `.casewright/assets/<sha256>.<ext>` (content-addressed, дедупликация), вставка через paste/drag/файл, ссылка из Markdown — относительный путь от файла кейса.
- Режим просмотра показывает изображение в пределах колонки; режим редактирования — миниатюру фиксированного размера без ресайза, выравнивания и перетаскивания.
- Отчёты и печать PDF включают изображения (inline data URI — печатное окно self-contained).
- Вне объёма: WYSIWYG для Steps/Systems/Acceptance (остаются компактными строками), ресайз/обтекание, запись видео и GIF экрана, облачные загрузки, изменение формата front matter.

## Capabilities

### New Capabilities

- `rich-text-authoring`: TipTap-редактор с Markdown-контрактом и ассеты изображений в текстах приложения.

### Modified Capabilities

Нет.

## Impact

Зависимости TipTap в `apps/desktop/package.json` (версии закрепляются), новые `components/editor/RichTextEditor.*`, правки `ObjectiveEditor`/`SetupControl`/`NotesField`, новый `services/assets.ts`, `utils/markdown.tsx` и `markdown-html.ts` (изображения), `store/slices/cases-slice.ts` (пересчёт путей при move). Формат кейса остаётся Markdown + YAML: изображение — обычная Markdown-ссылка на локальный ассет, поэтому файл читается и без редактора, и любым Markdown-инструментом.
