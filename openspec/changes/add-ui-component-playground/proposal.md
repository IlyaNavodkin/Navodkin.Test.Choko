# Proposal

## Why

Локальный `@codaa/ui` пока можно изучать только по исходникам. Перед использованием в Testoritto нужен отдельный каталог, в котором все публичные визуальные компоненты можно найти, увидеть в осмысленных композициях и проверить изменением props и состояния.

## What Changes

- Создать отдельное приложение `apps/ui-playground`: sidebar с группами и именами экспортов, поиск сверху, описание, варианты и интерактивные controls справа.
- Покрыть 102 публичных визуальных экспорта из `ui/index.ts` рабочими примерами; составные компоненты показывать внутри требуемых родителей. Зафиксировать соответствие каждого экспорта сценарию в `coverage-matrix.md`.
- Обеспечить начальный выбор, пустой поиск, keyboard/focus, достаточную ширину таблиц и layout, сброс и очистку demo state.
- Использовать React 19, TypeScript strict, Vite, `@codaa/ui`, CSS Modules и существующие Citadelic `--app-*` tokens. Все данные локальные; загрузки, аудио и destructive-looking действия остаются обратимыми демонстрациями.
- Добавить проверку полноты public exports, typecheck/build, frontend tests и реальные browser smoke проверки; завершить apply доступным локальным сервером и адресом.

Подтверждено поручением: сначала полная спецификация, затем отдельный этап реализации, сборки и запуска; каталог без бизнес-функций Testoritto. Предлагаемое решение: browser preview является обязательным результатом этого change, frontend пригоден для последующего размещения в Tauri 2. Отдельный native wrapper и installers в этот scope не входят. Блокирующих продуктовых вопросов нет.

## Capabilities

### New Capabilities

- `ui-component-catalog`: полный каталог публичных визуальных экспортов, группировка, поиск, выбор и доступная навигация.
- `ui-component-demos`: варианты, интерактивные сценарии, fixtures, управление состоянием и безопасная очистка эффектов.
- `ui-playground-preview`: отдельный workspace, библиотека и tokens, browser build/preview, проверка покрытия и инструкция запуска.

### Modified Capabilities

Нет. `openspec list --specs` на 2026-10-13 не обнаружил main specs; draft `add-testoritto-mvp` не изменяется.

## Impact

Будущие изменения ограничены `apps/ui-playground/`, добавлением workspace entry и независимых scripts, согласованным обновлением lockfile, документацией и этим OpenSpec change. Public API `@codaa/ui` не изменяется ради примеров; сначала используются consumer adapters. Доказанный дефект библиотеки фиксируется отдельно с воспроизведением и минимальной проверкой, без скрытого изменения поведения.

Вне scope: основное desktop-приложение, Casewright/fs/Git/IPC, HTTP backend, auth/SSO, второй UI Kit, другая палитра, hosted deployment, GitHub workflow, native packaging и архивирование незавершённого change. Работа выполняется в общей директории без переключения ветки и перезаписи параллельных изменений.
