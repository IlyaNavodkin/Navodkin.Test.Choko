# Proposal

Статус: draft для обсуждения, 2026-10-18. База — текущее приложение `app/` (NW.js + React + TypeScript), переписывание runtime не требуется.

## Why

Кейсы, прогоны и будущие баг-репорты повторяют определения, сокращения и ссылки на документы; автотестам нужны именованные наборы значений (`dev`, `stage`) для аргументов. Пользователь подтвердил отдельный раздел «Справочник» с двумя видами сущностей: **«Ссылка»** — сущность с описанием, которую можно вставлять в текст, и **«Аргументы»** — сущность с ключами и значениями, которая понадобится автотестам и отчётам прогонов.

## What Changes

- Новый раздел «Справочник» репозитория с записями двух видов:
  - `link` — название (обязательное), альтернативные названия, Markdown-описание, необязательный HTTP(S) URL, архив;
  - `arguments` — название, описание и типизированные значения `key → value` (string/number/boolean/url/enum), архив.
- Хранение — отдельные Markdown-файлы `.testoritto/glossary/<uuid>.md` (front matter + описание в теле). Существующий формат кейсов и прогонов не меняется; открытие репозитория ничего не создаёт.
- Вставка записи `link` в любое текстовое поле приложения как обычной Markdown-ссылки; в приложении ссылка читается как пояснение, неразрешённая ссылка не ломает текст.
- Снапшот использованных записей и выбранного набора аргументов фиксируется вместе с прогоном, чтобы правка справочника не меняла исторические результаты.
- Автотесты (change `add-playwright-automation`) ссылаются на значения набора `arguments` по `entryId` + `key` + revision.
- Вне объёма: загрузка внешних документов, секреты в значениях, автоподстановка похожих слов, использование записей как переменных шаблона.

## Capabilities

### New Capabilities

- `reference-book`: каталог записей «Ссылка» и «Аргументы», их хранение, вставка в текст и снапшоты в прогонах.

### Modified Capabilities

Нет: living specs в этой ветке отсутствуют, расширение описывается новой capability.

## Impact

Новые `apps/desktop/src/schemas/reference-book.ts`, `services/format/reference-book.ts`, `services/reference-book.ts` (fs), store slice и представление раздела; правки `utils/markdown.tsx`/`utils/markdown-html.ts` (рендер ссылок), `store/slices/runs-slice.ts` (снапшоты), навигация в `App.tsx`/`Sidebar.tsx`. Существующие кейсы, прогоны и конфигурация репозитория не переписываются.
