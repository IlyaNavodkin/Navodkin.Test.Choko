# Spec Delta

## Purpose

Продуктовый раздел «Автотесты» повторяет флоу прототипа — каталог, привязки кейсов, аргументы и окружения, invocation preview, запуск и результаты — на настоящем Rust v2 IPC с реальным исполнением Playwright.

## ADDED Requirements

### Requirement: Каталог и привязки автотестов
Система SHALL показывать каталог автотестов с поиском и фильтром архива, карточку создания/редактирования/архивации/удаления и несколько привязок на кейс с argument overrides; дубликат «тот же кейс + автотест + значения» блокируется диагностикой.

#### Scenario: Несколько привязок на кейс
- **WHEN** пользователь добавляет два автотеста к одному кейсу с разными аргументами
- **THEN** сохраняются отдельные binding ID; запуск создаёт отдельный invocation на каждую

#### Scenario: Архивация сохраняет историю
- **WHEN** автотест архивируется
- **THEN** он скрыт из нового выбора, старые bindings/snapshots/результаты доступны

### Requirement: Invocation preview перед запуском
Система SHALL показывать итоговые значения аргументов с приоритетом schema → autotest → binding → run, источником каждого значения и STALE-диагностикой при изменении источника; запуск с STALE блокируется.

#### Scenario: Просмотр и stale
- **WHEN** пользователь меняет источник после preview
- **THEN** preview помечен STALE, кнопка запуска заблокирована до обновления

### Requirement: Запуск и результаты
Система SHALL запускать только доверенный профиль явным действием, показывать start/poll/Stop, повтор упавших новым execution, attempts/retry/flaky, logs/errors/attachments как пассивные данные и импорт JSON/JUnit с preview и идемпотентным apply.

#### Scenario: Смешанный прогон
- **WHEN** прогон содержит ручные кейсы и связанные автотесты
- **THEN** ручной guide доступен, automation attempts видны отдельно и не стирают notes/checks/snapshots

#### Scenario: Сохранение отчётов в папку прогона
- **WHEN** пользователь выбирает «Сохранить в папку прогона»
- **THEN** Rust публикует только выбранные файлы с manifest, повтор идемпотентен, ручные файлы и Git index не меняются
