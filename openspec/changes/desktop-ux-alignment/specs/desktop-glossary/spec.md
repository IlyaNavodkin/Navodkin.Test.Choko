# Spec Delta

## Purpose

Нативный раздел «Справочник» хранит термины, сокращения, документы и окружения в версионированных Markdown-файлах репозитория и даёт типизированные значения окружений для аргументов автотестов.

## ADDED Requirements

### Requirement: Каталог записей справочника
Система SHALL показывать записи с типами term/abbreviation/document/environment, поиском по title/aliases/description, фильтрами типа и архива, создавать/редактировать/архивировать записи с валидацией и неизменяемым ID.

#### Scenario: Создание и редактирование записи
- **WHEN** пользователь создаёт запись «Окружение» с typed key=value и сохраняет
- **THEN** запись появляется в каталоге, ID стабилен, повторное открытие показывает значения

#### Scenario: Архив сохраняет историю
- **WHEN** пользователь архивирует запись, на которую ссылаются старые invocation snapshots
- **THEN** запись скрыта из нового выбора, старые снимки остаются читаемыми

#### Scenario: Guards выбора и навигации
- **WHEN** есть несохранённый draft записи и пользователь выбирает другую запись или закрывает раздел
- **THEN** система требует сохранить/отменить/отказаться; draft не теряется молча

### Requirement: Native хранение справочника
Система SHALL хранить записи в `.testoritto/glossary/<uuid>.md` с atomic writes, revision checks, сохранением unknown content и scoped Git ownership; открытие не выполняет миграцию.

#### Scenario: Внешнее изменение
- **WHEN** файл записи изменён вне приложения при чистом редакторе
- **THEN** редактор обновляется; при dirty draft требуется выбор пользователя

#### Scenario: Ошибка диска
- **WHEN** запись не удалась
- **THEN** показан failed-save без ложного saved state, draft удержан

### Requirement: Окружения для аргументов
Система SHALL давать picker entryId/key с типом и итоговым значением; архивная/отсутствующая запись блокирует новый запуск с `ENVIRONMENT_UNAVAILABLE`, секреты не записываются в переносимый manifest.

#### Scenario: Ссылка на prod/stage
- **WHEN** аргумент ссылается на запись окружения
- **THEN** manifest фиксирует значение и source revision; изменение записи не меняет старые результаты
