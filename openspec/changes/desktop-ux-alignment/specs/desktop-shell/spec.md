# Spec Delta

## Purpose

Продуктовый каркас десктопа — топбар, навигация пяти разделов, стартовый экран и глобальные хосты уведомлений — выглядит и ведётся как согласованные образцы, сохраняя все guards и native runtime.

## ADDED Requirements

### Requirement: App shell как в образцах
Система SHALL показывать `PageTopbar` с `PageBrand`, icon-навигацию разделов cases/runs/automation/git/glossary с `aria-current`, стартовый экран со списком recent-репозиториев как карточек и глобальные `ToastHost`/`BlockingOverlayHost`.

#### Scenario: Навигация между разделами
- **WHEN** пользователь открывает репозиторий и переключает разделы
- **THEN** виден топбар с пятью иконками, активный раздел подсвечен, Git показывает count-бейдж при изменениях

#### Scenario: Стартовый экран без репозитория
- **WHEN** репозиторий не открыт
- **THEN** показан крупный CTA «Открыть репозиторий» и список recent как карточек с путём, веткой и chevron

#### Scenario: Guards сохранены
- **WHEN** есть несохранённый draft, внешние изменения или suite recovery
- **THEN** навигация блокируется с понятным сообщением; данные не теряются

### Requirement: Адаптивность и токены
Система SHALL использовать `--app-*` токены Citadelic, типографику образца и брейкпоинты 1350/1050/800 с минимальной шириной 760 без горизонтального overflow.

#### Scenario: Узкий viewport
- **WHEN** окно 760 px
- **THEN** топбар перестраивается в grid, сайдбар сужается, overflow отсутствует

#### Scenario: Только Kit
- **WHEN** рендерится любой экран shell
- **THEN** используются только компоненты `@codaa/ui`, собственной палитры нет
